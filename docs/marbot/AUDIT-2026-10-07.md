# Pengujian Marka Plus — 7 Oktober 2026

Pengujian dilakukan pada source lokal Express/Prisma dan komponen chatbot Next.js. Ditemukan masalah pada pemilihan data, panduan, konteks percakapan, dan verifikasi hasil aksi. Perbaikan terbatas pada chatbot; tidak ada perubahan schema, flow approval ERP, atau data bisnis produksi.

## Bukti pengujian

- **16 suite baseline lulus:** native, native HTTP, security, Staff scope, capabilities, 204 resource contracts, planner, tenant, runtime context V2, tool HMAC V2, control plane V2, external HTTP, signature, secrets, config resolution, dan client. Fixture mencakup izin akses, validasi input, SSE, ownership, query, provider failure, injection, dan authority changes. Database operasional tidak digunakan untuk suite ini.
- **Tes regresi baru lulus:** `marbot-workflow-regression.unit.ts`, enam kelompok skenario pada tabel di atas, termasuk panduan Daily versus Weekly dan pertanyaan gabungan. Native/native HTTP/capabilities/planner/Staff scope dijalankan ulang setelah perubahan relevan. Pemeriksaan normalisasi project scope juga lulus.
- **Query PostgreSQL nyata lulus:** `marbot-weekly-query.integration.ts`, hanya pada `127.0.0.1:55440`, menggunakan tabel sementara dengan kolom yang sesuai query dan schema Prisma. Memeriksa pemilihan Weekly, periode September versus Oktober, status/nama, personal Staff/PM, data owner lain, project lain, company/tenant lain, ancestry yang tidak cocok, scope kosong, dan jumlah 25 dengan 20 baris tampil. Transaksi di-rollback; server lokal dihentikan setelah tes. Ini bukan pengujian endpoint ERP penuh atau bukti schema hosting.
- **Dua suite browser lulus:** `marbot-chat-recovery.browser.js` pada mobile 427×952 dan `marbot-ui.browser.js` pada mobile 390×844 serta desktop 1440×900. Menggunakan komponen `ChatbotDrawer` sebenarnya dengan API fixture. Memeriksa error 403/503, pemulihan pada kiriman berikutnya, tidak ada retry diam-diam, loading, tabel/jawaban panjang, tombol tutup, pembatalan/konfirmasi aksi, serta pembatalan respons lama ketika authority berubah. Screenshot mobile/desktop diperiksa visual; screenshot lama di repository dipertahankan.
- **TypeScript backend dan frontend lulus**, serta `git diff --check` dengan pengaturan CRLF Windows.
- `test:marbot-workflow` ditambahkan ke workflow CI. Tes lokalnya lulus; workflow GitHub belum dijalankan pada server CI dalam sesi ini.

## Menjalankan ulang

Dari `backend-express`, gunakan `npm run test:marbot-workflow` untuk regresi tanpa database. Tes PostgreSQL melalui `npm run test:marbot-weekly-query` hanya menerima `NODE_ENV=test` dan `DATABASE_URL` loopback pada port 55439/55440. Jalankan PostgreSQL uji terisolasi terlebih dahulu, gunakan `DEPLOYMENT_TARGET=local` dan `DIRECT_URL` yang sama dengan URL uji. Tes menggunakan tabel sementara dan tidak membutuhkan seed/migrasi.

Suite browser memerlukan `MARBOT_TEST_RUNTIME_PACKAGES` yang menunjuk paket Node runtime berisi Playwright, frontend dependencies, dan Edge. Jalankan kedua suite secara berurutan karena masing-masing memakai dev server Next dan route sementara. Script UI menulis screenshot ke `docs/marbot`; simpan screenshot lama sebelum pengulangan jika perlu dipertahankan.

## Batas hasil

Hasil ini menunjukkan skenario yang dijalankan lulus pada source lokal. Tidak dilakukan deployment, pengujian login end-to-end di hosting, mutasi bisnis produksi, atau panggilan provider AI berbayar. Provider diuji memakai fixture, sehingga kestabilan provider/WAF/jaringan hosting belum dibuktikan. Riwayat 403/500 dari screenshot lama tidak otomatis diselesaikan oleh audit lokal ini. Pemetaan bahasa alami tetap dibatasi aturan/planner yang tersedia; keberhasilan skenario teruji tidak membuktikan setiap formulasi pertanyaan dapat dipahami.

Audit ini tidak menggantikan laporan sebelumnya dan tidak menyatakan chatbot bebas seluruh masalah. Perubahan perlu masuk deployment normal agar berlaku pada website yang digunakan user.
